# 具身智能

具身智能（Embodied Intelligence）是人工智能与机器人技术的交叉前沿，关注智能体如何通过身体与物理世界进行交互，实现感知、理解与操作的统一。

## 研究方向概览

### 视觉-语言-动作模型 (VLA)

将视觉感知、语言理解与动作生成统一到端到端框架中：

- **RT-2** — 将 VLM 能力迁移到机器人控制
- **OpenVLA** — 开源视觉语言动作模型
- **π₀** — Physical Intelligence 的基础世界交互模型

### 仿真与数据

高效的仿真环境和数据生成是具身智能研究的基础设施：

- **Isaac Sim** — NVIDIA 的高保真机器人仿真平台
- **SAPIEN** — 可交互物体操作仿真环境
- **RoboCasa** — 大规模家庭环境仿真数据生成

### 操作与抓取

机器人操作（Manipulation）是具身智能最核心的能力之一：

- **灵巧手操作** — 多指手的精细操作策略
- **泛化抓取** — 面向开放世界的抓取能力
- **长时序任务规划** — 多步骤复杂任务的分解与执行

## 核心挑战

| 挑战 | 说明 |
|------|------|
| Sim-to-Real 迁移 | 仿真策略到真实世界的泛化 |
| 泛化能力 | 面对新物体、新场景的适应性 |
| 安全交互 | 人机共存环境下的安全保障 |
| 数据效率 | 减少对大规模实机数据的依赖 |
