# 工业异常检测

工业异常检测旨在利用计算机视觉技术自动识别生产过程中的缺陷与异常，是智能制造质量控制的核心环节。

## 研究方向概览

### 基于特征嵌入的方法

利用预训练模型提取特征，通过记忆库匹配或分布建模实现异常检测。代表方法包括：

- **PatchCore** — 基于核心集采样的 Patch 级特征匹配
- **SPADE** — 空间感知的异常分割方法
- **PaDiM** — 基于多变量高斯分布的异常定位

### 基于重建的方法

通过学习正常样本的重建模式，利用重建误差定位异常区域：

- **DRAEM** — 判别式重建异常嵌入模型
- **UniAD** — 统一的多类异常检测框架

### 多模态与大模型方法

结合视觉-语言模型探索零样本/少样本异常检测：

- **AnomalyGPT** — 基于大视觉语言模型的异常检测
- **WinCLIP** — 基于 CLIP 的零样本异常检测
